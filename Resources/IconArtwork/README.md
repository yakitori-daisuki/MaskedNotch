# App icon

Created in Apple's Icon Composer on 2026-09-08. Open `AppIcon.icon` to edit.
Original SVG artwork: `Display.svg` and `Mask.svg`, under the project GPL-3.0-only license.
The screen and black mask are separate layers; glass effects on the mask are disabled.
Xcode compiles the `.icon` resource using `ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon`.
The status menu's on/off icons are separate and unchanged.

Reference: https://developer.apple.com/documentation/xcode/creating-your-app-icon-using-icon-composer

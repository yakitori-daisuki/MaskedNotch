# 消して再表示する試験版

**2026-09-08の利用者動画で、点滅後に青い背景へ戻ることを確認。黒帯維持の試験は不合格です。**
点滅の実行と黒帯の維持は別の判定です。[動画の確認結果](VIDEO_REVIEW_2026-09-08.md)を参照してください。

`Masked Notch Blink.app` はデスクトップで0.5秒ごとに帯を非表示にし、
100ミリ秒後に同じ帯を再表示します。メニューバーの表示は「点滅」です。
通常版の再描画とは別の処理です。OSメニューより上のレベルには上げません。
他の背景が手前にある場合は、この試験版でも変化が見えない場合があります。

オフ・終了・ロック・スリープ・対象画面の消失ではタイマーと遅延再表示を停止します。
ロック中は従来の表示処理を使用し、点滅させません。
オン・オフとログイン時起動の設定は通常版とは独立しています。
比較中はログイン時起動をオフのままにしてください。
新しい版の起動時には他のMasked Notchへ終了を要求して重複を防ぎます。

ビルド:
```sh
MASKED_NOTCH_CONFIGURATION=Release ./script/build_and_run.sh --build
python3 script/package_variants.py --blink
```

出力は `build/Variants/Masked Notch Blink.app`。
壁紙・Thaw・OS設定の変更はありません。視覚効果・ちらつき・長時間負荷は未検証です。

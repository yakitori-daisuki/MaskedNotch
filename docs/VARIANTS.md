# A版・B版（手動比較用）

`bash script/build_variants.sh` で `build/Variants` に2個のアプリを生成します。
ダブルクリックで起動し、メニューバーのアイコン横にA/Bを表示します。

- **Masked Notch A.app**：既存の黒帯を0.5秒ごとに再描画。
- **Masked Notch B.app**：既存の黒帯を0.5秒ごとにOSメニューウィンドウの下へ再配置。明示的な再描画はしません。

両方とも通常の画面変更通知への処理は共通です。A/Bの動作は通常デスクトップだけで有効です。
今回のユーザー依頼による時間制限なしの実験版です。以前の110秒比較試験とは別です。
オフ・終了・ロック・スリープ・対象画面なしではタイマーを撤去し、デスクトップの帯が復帰すると再開します。
2026-09-08、利用者がA/B両方で黒を維持できたと報告したため、通常版にも低負荷だったAの再描画方式を採用しました。壁紙やOS設定は変更しません。

同時に重ならないよう、起動時に他のMasked Notch（通常/A/B）の終了を要求し、終了を確認してから表示します。
3秒以内に終了しなければ新しく起動した方が終了します。他のアプリには触れません。
各版は別のbundle IDを持ち、オン・オフや初回案内、ログイン時起動の状態も独立しています。
比較中はログイン時起動をオフのままにしてください。通常版に戻る時は通常版を起動してください。

メニュー「ノッチを隠す」で表示を切り替え、「終了」で停止できます。削除する場合は先にログイン時起動を解除して終了し、対象.appを削除してください。
ローカル用アドホック署名です。配布用署名・公証はしていません。
黒色の維持・文字の視認性・操作性・ロック画面・長時間負荷は未検証で、成功を保証する版ではありません。
